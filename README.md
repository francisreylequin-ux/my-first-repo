Project Name: Registration form 
Team Name: CodeRed
Description

The Sun Son Solar Registration Page is a user-friendly account creation form designed for a solar energy company. It allows users to enter their personal information, contact details, address, username, and password. Users can select an account type such as Customer, Employee, or Admin, with employees required to select their department. The form also includes contact number and password validation, Terms & Conditions agreement, and a login link for existing users. The design uses a clean, natural color scheme with a company logo and highlights clean energy, sustainability, and reliable solar solutions.
